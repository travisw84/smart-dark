SMART DARK SETTINGS

Set up Smart Dark.

Use a site's own dark theme where possible. Otherwise, Smart Dark adjusts its colours. Optional Jev image checks can help choose a theme.

Jev image checks

EXPERIMENTAL

Each check sends a screenshot of the visible page to TypeSafe / Jev. Screenshots can include private messages, documents and form values. Smart Dark does not save them. TypeSafe's terms govern how it processes and retains them.

Automatic checks are off by default. They capture the active page only while Chrome has focus. Smart Dark allows up to 30 image requests per UTC day and waits at least 30 seconds between automatic requests on the same tab. Manual checks count toward the daily limit. TypeSafe may charge for requests.

A result stays with the page until you navigate, change settings or its overall colours change. Checks stop if a frame cannot be inspected or a password, payment or one-time-code field is visible. These checks cannot identify every private page. Keep screenshot sharing off on sensitive sites.

Local appearance

Site theme first uses the website's dark CSS where available, then adjusts colours if needed. Try Dark Reader if a page looks wrong. Choose Original in the popup to leave a site unchanged.

Dark mode works without Jev. Smart Dark stores your key in this browser's extension storage and does not sync it or share it with websites. Chrome internal pages and the Web Store block theme extensions.
